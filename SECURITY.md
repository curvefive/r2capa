# Security policy

r2capa analyzes potentially hostile files but does not execute them. Treat radare2, capa, rules,
and plugins as part of the trusted analysis environment.

## Supported versions

Security fixes are provided for the latest release and the `main` branch.

## Reporting a vulnerability

Use GitHub's [private vulnerability reporting](https://github.com/curvefive/r2capa/security/advisories/new).
Include the affected version, platform, reproduction steps, and impact. Please allow a reasonable
amount of time for investigation before public disclosure.

Do not attach live malware. Use a minimal synthetic reproducer, or provide hashes and arrange a
private transfer with the maintainers.
